# Pocket Metropolis

An original, self-contained city-builder mini-game in the classic 90s isometric
style. One HTML file, no build step, no dependencies beyond an optional Google
Font — all art is drawn procedurally at runtime.

**This folder is standalone.** It shares no code or data with the rest of this
repository and can be moved to its own repo (or deleted) without affecting
anything else.

## Play it

Open `index.html` in any modern browser — phone or desktop. On a phone,
"Add to Home Screen" makes it launch like an app. Progress auto-saves to the
device via localStorage.

## What's in the game

- **Pick any starting budget**: presets from $10,000 to $500,000, a sandbox
  wallet, or type a custom amount.
- **Everything unlocked from day one** — no ranks, levels, or timers.
- Isometric tile map (44×44) with rivers, lakes, and woodland; roads become
  bridges over water.
- Zoning: residential / commercial / industrial parcels that develop through
  three density levels based on power, road access, demand, land value,
  pollution, and crime.
- Power grid: coal, wind, and nuclear plants with real capacity limits;
  electricity flows through wires and buildings (and wires can cross roads).
  Unpowered tiles flash ⚡ and brown out when a network is over capacity.
- City services (police, fire, school, hospital), parks, trees, and a stadium
  that raise land value and shape growth.
- Economy: monthly taxes vs. upkeep, adjustable tax rate, budget panel.
- RCI demand meter, population milestones, cosmetic traffic, smoke, and
  animated wind turbines.
- Touch-first controls: tap or drag to build, one-finger pan in Look mode,
  pinch to zoom, tap tiles to inspect them.
